Joy's 23rd Birthday Surprise — Project Files

What I added

- `index.html` — clean main file, links external CSS/JS.
- `styles.css` — extracted styles and theme.
- `script.js` — interactive behaviors (sparkles, mystery boxes, confetti, cake celebration, optional microphone input).

Quick start

1. Open `index.html` in a modern browser (double-click or serve via a static server).
2. To show Joy's photo permanently, place an image named `joy-photo.jpg` next to `index.html`. The page will fall back to a placeholder if not present.

Notes & tips

- Accessibility: focus outlines and reduced-motion respect are included.
- Performance: background sparkles and confetti are intentionally subtle; reduce the number by editing `script.js` if needed.
- To deploy: upload the files to any static host (GitHub Pages, Netlify, Vercel).

Want more?

- Opt-in synthesized celebratory audio is included for reveals and the cake celebration. You can disable sound with the toggle in the Mystery Gifts section.
- Add downloadable gift vouchers or a print-ready card.
- I can also bundle a ZIP with the files if you'd like.

Enjoy — and happy birthday to Joy 🎂✨
